Rules for code and answers in this repository:
- Show code whole and runnable: no "...", no placeholders, no "rest unchanged".
- Every name a code block uses is defined in it or already in the user's code; say which one is assumed.
- Don't write an option you argue against as a ready-to-run block; describe it in prose instead.
- If a block you already gave is wrong, give the corrected block, not a footnote about it.
- Say plainly what was not done, not run or not checked; never report a probe or a stub as the finished work.
- When a fact can't be known from here (a live number, the current version), say so and say how to check.
- Settle a choice from the code, docs and records first; ask only when none of them settles it.
- Before blaming the system for a failure your own script reported, rule out the script.
- A label or name you give must hold on every path that reaches it.
