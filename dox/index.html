p4-phi · dox

Documents you can work with your hands

p4-phi is the Claude Code plugin of the marketplace p4-marketplace that keeps what linked Claude desktop sessions hand each other, and retrieval from a project's own history. Each page here is one self-contained HTML file. Open one, change what it shows, and copy the calls and commands it prints.

Documents

  • The session tree

    Start orchestrators, workers and coworkers on a live tree. Detach to top level, reparent, split a queue by write set, and mark a session done. Each move prints the real call or command that performs it.

    session-tree.html

  • Delegation

    Choose a kind of task and see where p4-phi sends it: a worker, a background subagent or a background command. Step through the path its result takes back, and read the model and effort a worker starts with.

    session-levels.html

  • The puppeteer

    File an orchestrator in the sidebar section “puppeteers”, and it controls the orchestrators of other trees. Make each move on a model, read the lines p4-phi hands the puppeteer, archive a session through the app's approval card, and watch the board rewrite itself.

    puppeteer.html

  • Two trees that share a name

    p4-phi's session tree beside the two trees of ezexe/phi, the call tree its Zeckendorf register page draws and the ensemble of shard models phi_rank/tree.py builds. Change a small live drawing of each, then read what each is made of, what a link means, and how each grows, moves and leaves.

    tree-compare.html

  • Retrieval

    How p4-phi ranks a project's own history and finds the few entries it is confident of for a message: the corpus, the index, the lines it adds, how it learns from labels, the teacher model and the dictionary.

    retrieval.html

  • A session's files

    What p4-phi keeps in each linked session's folder and hands between sessions: turns and their deltas, the anchor, the rebase check, task lists, background tasks, the room beside one prompt and the caps.

    session-files.html

  • Claude Code settings

    The settings p4 writes into a project's local settings file, how it records and checks them again when Claude Code or a plugin changes, every other key and variable placed once, and the hook answers left to the app.

    claude-settings.html

  • Developing p4-phi while it is installed

    Load the copy under edit for one session, turn the installed copy off for the development project only, check each copy's data folder, run live checks on a clone, and move the installed copy only when a release is cut, all with Claude Code's own flags and settings.

    plugin-development.html
The plugin's code is in ezexe/p4, under lbiza/plugins/p4-phi. These pages are in the same repository, under dox/.
