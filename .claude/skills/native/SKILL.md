  about it; what this host can do, and anything newer, is read from https://code.claude.com/docs/en/overview.md and

- a correction from ezexe about how a p4 plugin behaves is a change to that plugin: plan it or make it,
  and write no memory for it. A fact about this machine or this checkout is a memory.
- See more: https://code.claude.com/docs/en/memory.md
