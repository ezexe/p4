## VLDS memory override (always active)

At the first message, launch the operator: the Agent tool, general-purpose, in the background, with the prompt "Read lbiza/plugins/vlds/hooks/operator-prompt.md and do what it says", then the store, the session id, the latest `now:` and the user's message. Act on its reply: the rules, past corrections and retractions that bear on the task. Its work in the store trains the project's models, so launch it every session.
